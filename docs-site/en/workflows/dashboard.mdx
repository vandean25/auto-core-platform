**Dashboard** is a command board you build, not a fixed report pack.

Empty dashboard copy: **No widgets configured yet.** How to add widgets is behind the info icon next to it.

That button is on Customers, Vehicles, Sales Orders, Workshop Orders, **Invoices**, Inventory, Vendors, Purchase Orders, and Purchase Bills.

### Saved views (favorites)

Lists with **Save as sidebar view** store filters and sort on the server (per user and tenant). Under **Favorites** in the sidebar you see **Personal** and **Team** sections; shared views show a **Team** badge.

<Steps>
  <Step title="Save a view">
    Filter the table, then **Save as sidebar view** and name it. The view appears under **Favorites** in the sidebar.
  </Step>
  <Step title="Team view">
    From the list **Views** menu or **Ctrl+K → Saved views**, use **Share with team** or **Unshare**. Others can **Save as personal view** to copy a team view.
  </Step>
  <Step title="Open and manage">
    Click a favorite, the list **Views** menu (including on phones), or **Ctrl+K** → **Saved views** / **Manage views** (open, rename, remove, share).
  </Step>
</Steps>

<Tip>
Views that lived only in the browser are imported once on first load after the update (toast with how many views were imported).
</Tip>

<Steps>
  <Step title="Filter a list the way you work">
    Search and sort until the table matches “open POs” or “today’s jobs.”
  </Step>
  <Step title="Add to dashboard">
    Click **Add to dashboard**. Name the widget. Choose list or a grouped metric.
  </Step>
  <Step title="Open Dashboard">
    Sidebar **Dashboard**. Widget titles and descriptions follow the UI language from your **profile** menu. Widgets stay live as other people receive stock or update jobs.
  </Step>
</Steps>

<Tip>
Long lists for widgets and favorites: **Workshop orders** (default **Opened** sort), **Invoices**, **Parts**, and **Vehicle stock** (with a status filter) load more rows as you scroll — up to **2,000** rows in memory. Other sorts on workshop orders stay paged.
</Tip>

## Global search

**Ctrl+K** (Windows) or **Cmd+K** (Mac) opens **Global Search**. Placeholder: **Search parts, customers, vehicles, jobs…**

Type at least two characters (a digits-only query, such as a phone number without spaces, needs only one digit). Hits at other sites show **Other site**.

### Search groups

Results are grouped by type (visible groups depend on your role):

| Group | Examples |
| --- | --- |
| **Customers** | Name, company, email, phone; **legacy customer no. (source system)** exact or prefix |
| **Vehicles** | Plate, VIN, make/model; **legacy vehicle no. (source system)** exact or prefix |
| **Vehicle stock** | Dealer stock vehicles at the site |
| **Workshop orders** | Order number, plate, customer |
| **Appointments**, **estimates**, **sales orders**, **vehicle sales** | Number, customer, plate |
| **Invoices**, **credit notes** | Document number |
| **Parts**, **labor operations** | SKU, description, labor code |
| **Vendors**, **purchase orders**, **purchase bills** | Name, number |
| **Employees**, **users**, **legal entities**, **sites** | Name, short code (by role) |

### Navigate and create

With no type prefix, the palette also lists:

- **Navigate** — the same destinations as the grouped sidebar (filtered by your role).
- **Settings** — deep links to settings tabs once you start typing (only tabs that are not already in the sidebar).
- **Create** — e.g. **Create workshop order**, **Create Sales Order**, **Create Purchase Order**, **Create Purchase Bill**.

On a customer or vehicle detail page, **Create workshop order** opens [Workshop intake](/en/workflows/workshop-intake) with that record prefilled.

### Prefix filters

Start the query with a prefix to search one type only (help text appears in the palette):

| Prefix | Type |
| --- | --- |
| `k:` | Customers |
| `fz:` | Vehicles and vehicle stock |
| `a:` | Workshop orders |
| `tm:` | Appointments |
| `kv:` | Estimates |
| `ka:` | Sales orders |
| `vk:` | Vehicle sales |
| `r:` | Invoices |
| `g:` | Credit notes |
| `t:` | Parts |
| `aw:` | Labor operations |
| `l:` | Vendors |
| `b:` | Purchase orders |
| `er:` | Purchase bills |
| `m:` | Employees |
| `u:` | Users |
| `f:` | Legal entities |
| `s:` | Sites |

Example: `r:RE-2026` finds invoices with that number. Legacy import IDs (e.g. from incadea) work with `k:` or `fz:` on an exact ID or prefix — not on arbitrary substrings in the middle.

### Recently opened

After you open a hit, the palette remembers it under **Recently opened** (per user and tenant). You can remove individual entries there.

### Actions on the current record

On a customer, vehicle, or workshop order detail page, the palette shows **Current record** with quick actions from the action registry — for example **Vehicle check-in** on an order or **Create workshop order** from a customer. On a workshop order you can also run actions such as **Assign mechanic**, mark tasks **Done** / **Reopen task**, and **Job card PDF** from search when your role and order status allow it.

### Workshop command

When the input is empty and your role may plan workshop work, you see **Workshop command (text or voice)**. Type or dictate a sentence (appointment, service, loaner), **Review** shows a preview without saving, and **Apply proposal** creates the order and reservation — or queues an approval proposal when your tenant requires agent review. Personal tokens from the sentence (surname, plate, VIN) are kept only briefly to replay the command and are purged on a schedule.

<Tip>
Lists stay live. When someone else receives stock or updates a job, the widgets update.
</Tip>
