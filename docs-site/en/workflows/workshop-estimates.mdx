---
title: "Estimates (list)"
description: "Search and filter every estimate at the site, then jump from a row to the order and version."
---

**Estimates** in the sidebar (`/workshop/estimates`) is the site-wide estimate list — not the editor on a single workshop order. In-app subtitle: *All estimates at this site. One click opens the order with that version.*

OWNER, ADMIN, and SALES see the item under **Workshop**.

<Steps>
  <Step title="Open the list">
    Sidebar → **Estimates** (menu label **Kostenvoranschläge** in German).
  </Step>
  <Step title="Search and filter">
    Search: **No., customer, plate**. Status, customer, and **Sent from / to** narrow the table. **Show older versions** includes earlier estimate versions (by default only the current version per number).
  </Step>
  <Step title="Jump to the order">
    Click a row or **Open estimate** — you land on the workshop order with that version selected. Create, send, and revise estimates on the order’s **Cost estimate** card (see [Workshop orders](/en/workflows/workshop-orders)).
  </Step>
</Steps>

| Column | Meaning |
| --- | --- |
| **Number** | Estimate number |
| **Order** | Linked workshop order |
| **Customer** / **Plate** | Vehicle context |
| **Status** | Draft, sent, decided, etc. |
| **Sent at** / **Valid until** | Send and expiry dates |
| **Total** | Gross total for that version |

<Tip>
With many rows the table loads in pages; **Load more** fetches older entries. Search and sort apply only to loaded pages — filter first, then load more if needed.
</Tip>
