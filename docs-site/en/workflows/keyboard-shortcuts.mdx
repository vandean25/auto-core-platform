title: "Keyboard shortcuts"
description: "Global search, navigation, and lists without the mouse — including the in-app help overlay."
---

ACP attaches shortcuts to the layer that works on almost every screen. In the **profile** menu, **Single-key shortcuts** controls whether letter keys work without Ctrl/Cmd.

Press **?** (without Ctrl/Cmd) when single-key shortcuts are on — the same entries as on this page. You can also open help from **Profile → Keyboard shortcuts**.

## Always on

| Shortcut | Action |
| --- | --- |
| **Ctrl+K** / **Cmd+K** | Open **Global Search** ([Dashboard and search](/en/workflows/dashboard)) |
| **Ctrl+B** / **Cmd+B** | Show or hide the sidebar (icon mode on laptop) |
| **Arrow up / down** | Move row focus in supported tables |

## With single-key shortcuts (profile)

| Shortcut | Action |
| --- | --- |
| **?** | **Keyboard shortcuts** help overlay |
| **G**, then **W** / **C** / **V** | **Workshop Orders** / **Customers** / **Vehicles** (do not hold both keys) |
| **J** / **K** | Focus next / previous loaded row (lists with row focus) |
| **X** | Select or clear the focused row (when the list supports multi-select) |
| **O** | **Open** the focused row in full (detail page) |
| **Enter** | Activate the row link (same as click) |

Clicking a row opens a **peek** side sheet first; use **Open** in the sheet or **O** for the detail page.

<Warning>
**G**, **J**, **K**, **X**, and **O** do not run while focus is inside an input — press **Esc** or click outside first. With single-key shortcuts off, **Ctrl+K**, **Ctrl+B**, and arrow keys still work.
</Warning>
