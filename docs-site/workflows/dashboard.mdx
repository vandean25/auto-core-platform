**Dashboard** ist ein Kommandoboard, das Sie selbst bauen — kein festes Report-Paket. Untertitel: Bauen Sie Ihre Kommandozentrale aus gespeicherten Tabellenfiltern.

Leerer Dashboard-Text: **Noch keine Widgets. Öffnen Sie eine Listenansicht, setzen Sie Filter und klicken Sie auf Zum Dashboard hinzufügen.**

Dieser Button gibt es bei Kunden, Fahrzeugen, Kundenaufträgen, Werkstattaufträgen, Lager, Lieferanten, Bestellungen und Eingangsrechnungen.

<Steps>
  <Step title="Liste so filtern, wie Sie arbeiten">
    Suchen und sortieren, bis die Tabelle z. B. „offene Bestellungen“ oder „heutige Jobs“ zeigt.
  </Step>
  <Step title="Zum Dashboard hinzufügen">
    Klicken Sie **Zum Dashboard hinzufügen**. Benennen Sie das Widget. Wählen Sie Liste oder gruppierte Kennzahl.
  </Step>
  <Step title="Dashboard öffnen">
    In der Seitenleiste **Dashboard**. Widgets bleiben live, wenn andere Ware einbuchen oder Aufträge aktualisieren.
  </Step>
</Steps>

## Globale Suche

**Strg+K** (Windows) oder **Cmd+K** (Mac) öffnet die **Globale Suche**. Platzhalter: **Teile, Kunden, Fahrzeuge, Aufträge…**

Geben Sie mindestens zwei Zeichen ein (bei einer reinen Ziffernfolge, z. B. einer Telefonnummer ohne Leerzeichen, reicht eine Ziffer). Treffer aus anderen Standorten zeigen **Anderer Standort**.

### Suchgruppen

Die Ergebnisse erscheinen nach Typ gruppiert:

| Gruppe | Beispiel |
| --- | --- |
| **Kunden** | Name, Firma, E-Mail, Telefon |
| **Fahrzeuge** | Kennzeichen, FIN, Marke/Modell |
| **Fahrzeugbestand** | Händler-Bestandsfahrzeuge am Standort |
| **Werkstattaufträge** | Auftragsnummer, Kennzeichen, Kunde |
| **Rechnungen** | Rechnungsnummer |
| **Teile** | SKU oder Beschreibung → Bestandsjournal des Teils |

### Navigation und Anlegen

Ohne Typ-Präfix listet die Palette zusätzlich:

- **Navigation** — dieselben Ziele wie in der gruppierten Seitenleiste (nach Rolle gefiltert).
- **Einstellungen** — direkte Links zu Einstellungs-Tabs, sobald Sie tippen (nur Tabs, die nicht schon in der Seitenleiste stehen).
- **Anlegen** — z. B. **Werkstattauftrag anlegen**, **Kundenauftrag anlegen**, **Bestellung anlegen**, **Eingangsrechnung anlegen**.

Auf einer Kunden- oder Fahrzeugdetailseite füllt **Werkstattauftrag anlegen** die [Fahrzeugannahme](/workflows/workshop-intake) mit diesem Datensatz vor.

### Präfix-Filter

Mit einem Präfix am Anfang der Eingabe suchen Sie nur in einem Typ (Hilfetext steht in der Palette):

| Präfix | Typ |
| --- | --- |
| `k:` | Kunden |
| `fz:` | Fahrzeuge und Fahrzeugbestand |
| `a:` | Werkstattaufträge |
| `r:` | Rechnungen |
| `t:` | Teile |

Beispiel: `r:RE-2026` findet Rechnungen mit dieser Nummer.

### Zuletzt geöffnet

Nach dem Öffnen eines Treffers merkt sich die Palette den Datensatz unter **Zuletzt geöffnet** (pro Benutzer und Mandant). Einzelne Einträge können Sie dort entfernen.

### Aktionen am aktuellen Datensatz

Stehen Sie auf einer Kunden-, Fahrzeug- oder Werkstattauftragsdetailseite, zeigt die Palette den Block **Aktueller Datensatz** mit Schnellaktionen aus dem Aktionsregister — z. B. **Fahrzeugannahme** am Auftrag oder **Werkstattauftrag anlegen** vom Kunden. Am Werkstattauftrag können u. a. **Mechaniker zuweisen**, Aufgaben **Erledigt** / **Wieder öffnen** und **Werkstattkarte als PDF** aus der Suche heraus laufen (sichtbar nach Rolle und Auftragsstatus).

<Tip>
Listen bleiben live. Wenn jemand anderes Ware einbucht oder einen Auftrag ändert, aktualisieren sich die Widgets.
</Tip>
