**Dashboard** ist ein Kommandoboard, das Sie selbst bauen — kein festes Report-Paket.

Leerer Dashboard-Text: **Noch keine Widgets vorhanden.** Wie Sie Widgets hinzufügen, steht im Hinweis hinter dem Info-Symbol daneben.

Dieser Button gibt es bei Kunden, Fahrzeugen, Kundenaufträgen, Werkstattaufträgen, **Rechnungen**, Lager, Lieferanten, Bestellungen und Eingangsrechnungen.

### Gespeicherte Ansichten (Favoriten)

Listen mit **Als Seitenleisten-Ansicht speichern** merken sich Filter und Sortierung auf dem Server (pro Benutzer und Mandant). In der Seitenleiste unter **Favoriten** gibt es Abschnitte **Persönlich** und **Team**; geteilte Ansichten tragen das Badge **Team**.

<Steps>
  <Step title="Ansicht speichern">
    Tabelle filtern, dann **Als Seitenleisten-Ansicht speichern** — Name vergeben. Die Ansicht erscheint unter **Favoriten** in der Seitenleiste.
  </Step>
  <Step title="Team-Ansicht">
    Über das **Ansichten**-Menü an der Liste oder **Strg+K → Gespeicherte Ansichten** wählen Sie **Mit Team teilen** bzw. **Teilen aufheben**. Team-Ansichten können Sie mit **Als eigene Ansicht speichern** duplizieren.
  </Step>
  <Step title="Wieder öffnen und verwalten">
    Favorit anklicken, Listen-**Ansichten**-Menü (auch am Smartphone) oder **Strg+K** → **Gespeicherte Ansichten** / **Ansichten verwalten** (öffnen, umbenennen, entfernen, teilen).
  </Step>
</Steps>

<Tip>
Frühere Ansichten, die nur im Browser lagen, übernimmt ACP einmalig beim ersten Laden nach dem Update (Toast mit der Anzahl übernommener Ansichten).
</Tip>

<Steps>
  <Step title="Liste so filtern, wie Sie arbeiten">
    Suchen und sortieren, bis die Tabelle z. B. „offene Bestellungen“ oder „heutige Jobs“ zeigt.
  </Step>
  <Step title="Zum Dashboard hinzufügen">
    Klicken Sie **Zum Dashboard hinzufügen**. Benennen Sie das Widget. Wählen Sie Liste oder gruppierte Kennzahl.
  </Step>
  <Step title="Dashboard öffnen">
    In der Seitenleiste **Dashboard**. Widget-Titel und -Beschreibungen folgen der Oberflächensprache aus dem **Profil**. Widgets bleiben live, wenn andere Ware einbuchen oder Aufträge aktualisieren.
  </Step>
</Steps>

<Tip>
Lange Listen für Widgets und Favoriten: **Werkstattaufträge** (Sortierung **Eröffnet**), **Rechnungen**, **Teile** und **Fahrzeugbestand** (mit Statusfilter) laden beim Scrollen weitere Zeilen nach — bis höchstens **2.000** Zeilen im Speicher. Andere Sortierungen bei Werkstattaufträgen bleiben paginiert.
</Tip>

## Globale Suche

**Strg+K** (Windows) oder **Cmd+K** (Mac) öffnet die **Globale Suche**. Platzhalter: **Teile, Kunden, Fahrzeuge, Aufträge…**

Geben Sie mindestens zwei Zeichen ein (bei einer reinen Ziffernfolge, z. B. einer Telefonnummer ohne Leerzeichen, reicht eine Ziffer). Treffer aus anderen Standorten zeigen **Anderer Standort**.

### Suchgruppen

Die Ergebnisse erscheinen nach Typ gruppiert (sichtbare Gruppen hängen von Ihrer Rolle ab):

| Gruppe | Beispiel |
| --- | --- |
| **Kunden** | Name, Firma, E-Mail, Telefon; **Alte Kundennr. (Vorsystem)** exakt oder als Präfix |
| **Fahrzeuge** | Kennzeichen, FIN, Marke/Modell; **Alte Fahrzeugnr. (Vorsystem)** exakt oder als Präfix |
| **Fahrzeugbestand** | Händler-Bestandsfahrzeuge am Standort |
| **Werkstattaufträge** | Auftragsnummer, Kennzeichen, Kunde |
| **Termine**, **Kostenvoranschläge**, **Kundenaufträge**, **Fahrzeugverkäufe** | Nummer, Kunde, Kennzeichen |
| **Rechnungen**, **Gutschriften** | Belegnummer |
| **Teile**, **Arbeitswerte** | SKU, Beschreibung, Arbeitswert-Code |
| **Lieferanten**, **Bestellungen**, **Eingangsrechnungen** | Name, Nummer |
| **Mitarbeiter**, **Benutzer**, **Firmen**, **Standorte** | Name, Kürzel (nach Rolle) |

### Navigation und Anlegen

Ohne Typ-Präfix listet die Palette zusätzlich:

- **Navigation** — dieselben Ziele wie in der gruppierten Seitenleiste (nach Rolle gefiltert).
- **Einstellungen** — direkte Links zu Einstellungs-Tabs, sobald Sie tippen (nur Tabs, die nicht schon in der Seitenleiste stehen).
- **Anlegen** — z. B. **Werkstattauftrag anlegen**, **Kundenauftrag anlegen**, **Bestellung anlegen**, **Eingangsrechnung anlegen**.

Auf einer Kunden- oder Fahrzeugdetailseite füllt **Werkstattauftrag anlegen** die [Fahrzeugannahme](/workflows/workshop-intake) mit diesem Datensatz vor.

### Präfix-Filter

Mit einem Präfix am Anfang der Eingabe suchen Sie nur in einem Typ (Hilfetext steht in der Palette):

| Präfix | Typ |
| --- | --- |
| `k:` | Kunden |
| `fz:` | Fahrzeuge und Fahrzeugbestand |
| `a:` | Werkstattaufträge |
| `tm:` | Termine |
| `kv:` | Kostenvoranschläge |
| `ka:` | Kundenaufträge |
| `vk:` | Fahrzeugverkäufe |
| `r:` | Rechnungen |
| `g:` | Gutschriften |
| `t:` | Teile |
| `aw:` | Arbeitswerte |
| `l:` | Lieferanten |
| `b:` | Bestellungen |
| `er:` | Eingangsrechnungen |
| `m:` | Mitarbeiter |
| `u:` | Benutzer |
| `f:` | Firmen (Rechtsträger) |
| `s:` | Standorte |

Beispiel: `r:RE-2026` findet Rechnungen mit dieser Nummer. Import-IDs aus Altsystemen (z. B. incadea) finden Sie mit `k:` oder `fz:` bei exakter Nummer oder Präfix — nicht bei Teilstrings mitten in der Nummer.

### Zuletzt geöffnet

Nach dem Öffnen eines Treffers merkt sich die Palette den Datensatz unter **Zuletzt geöffnet** (pro Benutzer und Mandant). Einzelne Einträge können Sie dort entfernen.

### Aktionen am aktuellen Datensatz

Stehen Sie auf einer Kunden-, Fahrzeug- oder Werkstattauftragsdetailseite, zeigt die Palette den Block **Aktueller Datensatz** mit Schnellaktionen aus dem Aktionsregister — z. B. **Fahrzeugannahme** am Auftrag oder **Werkstattauftrag anlegen** vom Kunden. Am Werkstattauftrag können u. a. **Mechaniker zuweisen**, Aufgaben **Erledigt** / **Wieder öffnen** und **Werkstattkarte als PDF** aus der Suche heraus laufen (sichtbar nach Rolle und Auftragsstatus).

### Werkstatt-Befehl

Ist die Eingabe leer und Ihre Rolle darf Werkstatt planen, erscheint **Werkstatt-Befehl (Text oder Sprache)**. Sie tippen oder diktieren einen Satz (z. B. Termin, Leistung, Leihwagen), **Prüfen** zeigt eine Vorschau ohne Speichern, **Vorschlag übernehmen** legt erst dann Auftrag und Reservierung an — oder stellt einen Freigabe-Vorschlag bereit, wenn Ihr Mandant Agenten-Freigaben verlangt. Persönliche Daten aus dem Satz (Nachname, Kennzeichen, FIN) werden nur kurz für die Wiederholung des Befehls vorgehalten und regelmäßig gelöscht.

<Tip>
Listen bleiben live. Wenn jemand anderes Ware einbucht oder einen Auftrag ändert, aktualisieren sich die Widgets.
</Tip>
