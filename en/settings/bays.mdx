---
title: "Bays"
description: "Name the stalls on the workshop board and the order they appear."
---

Use **Settings → Bays** for physical service bays. Inactive bays stay in the list but should not take new jobs.

Search: **Search bays...** Top-right: **+ Bay**.

<Steps>
  <Step title="Create">
    **+ Bay** → **Create Bay**. Name required. Sort order a whole number ≥ 0. New bays start Active.
  </Step>
  <Step title="Rename or reorder in the row">
    Name and sort order save when you leave the field.
  </Step>
  <Step title="Park a bay">
    **Active** / **Inactive** toggles without deleting history.
  </Step>
</Steps>

## Columns

| Column | How you change it |
| --- | --- |
| **Name** | Inline edit |
| **Active** | Toggle button |
| **Sort Order** | Inline edit |

Right-click → **Delete**. Unused bays can disappear (**Bay deleted**). A bay still on a workshop order is deactivated instead (**Bay deactivated**).

<Check>
Sort order is the sequence on the board, not a street address. Keep numbers sparse (10, 20, 30) if you insert stalls later.
</Check>
