ACP attaches shortcuts to the layer that works on almost every screen. Press **?** (without Ctrl/Cmd) to open the **Keyboard shortcuts** overlay in the app — the same entries as on this page.

## Global

| Shortcut | Action |
| --- | --- |
| **Ctrl+K** / **Cmd+K** | Open **Global Search** ([Dashboard and search](/en/workflows/dashboard)) |
| **Ctrl+B** / **Cmd+B** | Show or hide the sidebar (icon mode on laptop) |
| **?** | **Keyboard shortcuts** help overlay |

## Navigation (G sequence)

Press **G**, then the second letter — do not hold both keys together.

| Sequence | Destination |
| --- | --- |
| **G**, **W** | **Workshop Orders** |
| **G**, **C** | **Customers** |
| **G**, **V** | **Vehicles** |

## Lists

In supported tables (e.g. **Customers**, **Vehicles**, **Workshop Orders**):

| Shortcut | Action |
| --- | --- |
| **Arrow up / down** | Move row focus |
| **O** | **Open** the focused row in full (detail page) |
| **Enter** | Activate the row link (same as click) |

Clicking a row opens a **peek** side sheet first; use **Open in full** in the sheet or **O** for the detail page.

<Warning>
**G** sequences and **O** do not run while focus is inside an input — press **Esc** or click outside first.
</Warning>
