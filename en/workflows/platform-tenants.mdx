---
title: "Platform tenants"
description: "Super-admins create and update workshop tenants. Everyone else never sees this list."
---

Sidebar **Tenants** appears only when `platformRole` is **SUPER_ADMIN**. It is not a workshop settings tab.

Click a row for the tenant sheet. Create is a dialog (name, plan). Updates save on the sheet. Status badges show whether the tenant is active.

<Warning>
This is platform data, not your shop’s customers. Do not treat it as CRM. Tenant isolation still applies inside each workshop.
</Warning>
