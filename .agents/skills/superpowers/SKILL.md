# Superpowers skills

ACP keeps only the three mandatory skills from obra/superpowers. Each lives in a subdirectory of `.agents/skills/superpowers/` as `SKILL.md`:

- [test-driven-development](./test-driven-development/SKILL.md) — Red-Green-Refactor for behaviour changes and bugfixes
- [systematic-debugging](./systematic-debugging/SKILL.md) — root-cause analysis when tests or builds fail
- [verification-before-completion](./verification-before-completion/SKILL.md) — run checks before claiming work is complete
